# APEP Professional Resource Library

These resources are decision and execution instruments for AI practitioners, entrepreneurs, marketers and business leaders.

## Resource standard

Each resource should help the user define an outcome, assess evidence, establish controls, test a workflow or make a documented decision. APEP does not treat generic checklists, hype-driven tool lists or decorative worksheets as professional standards.

## Current instruments

- AI Workflow Governance Framework
- AI Tool Due Diligence Framework
- AI Use-Case Business Case
- AI Content Operations Brief
- AI Prompt Quality Assurance Protocol
- AI Adoption Executive Scorecard
