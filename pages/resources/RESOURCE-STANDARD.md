# APEP Resource Standard

APEP professional resources are not generic worksheets or decorative downloads. A publishable resource must have a defined user, decision or workflow, a clear operating objective, explicit inputs/outputs, evidence or validation criteria where applicable, ownership, review controls, and a usable path to action.

## Minimum acceptance gates

1. **Purpose** — the business/learning problem is explicit.
2. **Structure** — the user can execute the method without guessing the intended sequence.
3. **Evidence** — claims and decisions can be supported or tested.
4. **Controls** — privacy, security, quality and human-review considerations are addressed where relevant.
5. **Decision output** — the resource produces a documented recommendation, approval, plan, score or operating record.
6. **Ownership** — an accountable owner and review point can be recorded.
7. **Usability** — readable, printable and usable in a real workflow.

Resources that do not meet these gates should remain drafts, not be presented as professional APEP assets.
