How to use this directory

Start with the job

These are practical starting points, not endorsements or a claim that one tool is best for every user. Product features, limits and pricing can change, so always confirm current details on the official site before adoption.

1. Define the outcome

Research, write, design, create media, automate, market, code or organise knowledge.

2. Compare fit

Check capability, integrations, learning curve, reliability and whether it fits your actual workflow.

3. Check risk

Review privacy, data handling, permissions, security controls and human-review requirements before sensitive use.

4. Test before committing

Run a representative task using a free tier or trial where available, then evaluate the output rather than the marketing promise.

Directory review date: September 6, 2026. Official product links are provided so visitors can verify current capabilities, terms and pricing directly with each vendor.

APEP decision standard

What earns a place in the directory?

Capability

Does the product actually perform the job it is being considered for?

Reliability

Can the workflow produce consistent enough results for its intended use?

Privacy & security

What data, permissions and organisational risks must the user understand?

Workflow fit

Does the tool reduce friction or simply add another disconnected application?

Value

Is the capability worth the money, time, learning curve and operational dependency?

Human oversight

Where accuracy, rights, safety or business impact matter, keep an appropriate human review step.
