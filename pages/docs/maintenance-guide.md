# Maintenance Guide

## Routine updates

Keep visual changes in `style.css`, content changes in `index.html`, public release metadata in `config/app-config.js`, and interaction changes in `js/`.

## Assets

Store approved local images in `assets/` using descriptive lowercase filenames. Use modern compressed formats where browser support permits and provide accurate alternative text.

## Release maintenance

Run the QA checklist before every RC submission. Do not advance a release until the independent audit has passed.
