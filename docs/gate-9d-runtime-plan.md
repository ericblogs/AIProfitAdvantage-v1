# Gate 9D Runtime Plan

1. Admin certification page authenticates and loads candidates/ledger.
2. Student certification page authenticates and shows authoritative records or empty state.
3. Eligibility prevents incomplete learners from issuance.
4. Authorized admin issuance creates a unique ledger credential and audit event.
5. Reissue supersedes the prior credential.
6. Revocation requires a reason and creates an audit event.
7. Public verification returns controlled credential data only.
8. Regression confirms payment, provider governance, authentication, onboarding and Course Player remain unchanged.
