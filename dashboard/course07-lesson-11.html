Lesson 11: Generative AI + Power BI Analysis

Outcome

Use generative AI to accelerate analytical exploration while preserving verification.

Framework

Prompt → inspect → calculate → challenge → verify → communicate.

Practice

Ask an AI assistant for hypotheses about a dataset, then test each hypothesis independently.

Deliverable

Create an AI-assisted analysis log showing prompts and verification steps.

Mastery check

Identify two hallucination risks in AI-assisted analytics.
