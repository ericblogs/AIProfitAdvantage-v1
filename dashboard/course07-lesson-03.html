Lesson 03: Data Types, Sources & Data Quality

Outcome

Recognize structured, semi-structured and unstructured data and assess source reliability.

Framework

Accuracy, completeness, consistency, timeliness, validity and uniqueness.

Practice

Profile a sample dataset and list five quality checks before analysis.

Deliverable

Produce a data-quality checklist.

Mastery check

Explain how poor source quality can create a convincing but false insight.
