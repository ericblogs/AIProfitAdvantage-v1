# Lesson 07 — SEO & AI-Assisted Search

## Outcome
Build search content around genuine user intent while using AI responsibly.

## Core concepts
SEO starts with search intent, topical relevance, useful information, technical accessibility, internal linking, and trustworthy references. AI can accelerate keyword clustering, briefs, outlines, FAQs, and content audits, but it should not produce mass low-value pages.

### Workflow
**Intent research → topic map → evidence collection → brief → draft → expert review → optimization → measurement.**

## Practical exercise
Select one topic and classify ten queries as informational, commercial, navigational, or transactional. Design one content asset for each cluster.

## Deliverable
Create an SEO content brief with primary intent, audience, entities/topics, questions, evidence sources, internal links, CTA, and success metric.

## Mastery check
Why is search intent more important than simply inserting keywords?
