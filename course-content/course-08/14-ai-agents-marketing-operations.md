# Lesson 14 — AI Agents for Marketing Operations

## Outcome
Understand where agentic systems can safely support marketing operations.

## Agent pattern
An agent combines a goal, context, tools, policies, execution loop, state, and evaluation. Marketing agents may research, classify, draft, monitor, or route work.

Use least privilege, bounded tools, approval gates, audit logs, and explicit stop conditions. Never grant an agent unrestricted authority over spend, customer records, or public claims.

## Practical exercise
Design an agent that monitors campaign performance and prepares a daily exception report without changing campaign settings.

## Deliverable
Create an agent specification covering objective, tools, permissions, memory, guardrails, evaluation, and human approval points.

## Mastery check
Which marketing actions should always require human authorization?
