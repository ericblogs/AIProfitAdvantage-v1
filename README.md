# AI Profit Advantage

Static marketing site for AI Profit Advantage, an AI education platform founded by Prince S. Eric John.

## RC-1.2.0 Production Release Candidate

This release contains the approved business-infrastructure foundation, production metadata, accessible navigation improvements, search-engine discovery files and GitHub Pages deployment preparation. Payment, authentication, analytics, CRM, LMS, marketplace and community features remain intentionally deferred.

## Run locally

Open `index.html` with a local static server. For example, in VS Code use Live Server. Do not open production pages through a `file://` URL because JavaScript modules require an HTTP(S) origin.

## Governance

No changes outside the approved Release Candidate scope may be introduced without formal approval. Future-release enhancements must be documented and deferred.
