Security boundary: this page does not query course_purchases, auth.users, or student_profiles directly from the browser. It invokes the authenticated-only public.admin_get_payments() function, which is security-definer protected by public.is_current_user_admin(). No refund, cancellation, manual payment marking, entitlement, enrollment, or Paystack controls are exposed in this gate.
Ledger semantics: course_purchases is the authoritative course-payment purchase ledger. course_prices is pricing configuration, course_entitlements is access authorization, and enrollments is learning enrollment. An empty purchase ledger is a valid state when no paid course transaction has yet been completed.
